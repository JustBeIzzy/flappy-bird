- **Bergerak Kiri / Kanan:** `A` / `D` atau `Panah Kiri` / `Panah Kanan`
- **Lompat:** `Tombol Spasi` (`Spacebar`)
- **Serang / Aksi:** `J` atau `Klik Kiri Mouse`
